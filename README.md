# 許文修 | Wen-Hsiu Hsu

我的個人網站，用來介紹自己和放履歷。

**網站：** [https://resume.hsiu.soy](https://resume.hsiu.soy)

## 網站內容

網站上有我的工作經歷、技能、做過的專案和興趣。

-   中文與英文兩種語言
-   履歷可以下載成 PDF
-   閱讀時，側邊欄會標示目前所在的章節
-   桌機、平板和手機都能瀏覽
-   捲動頁面時有動畫效果

## 技術

用 Nuxt 3（Vue 3 + TypeScript）開發，樣式用 UnoCSS。

-   履歷資料放在 GitHub Gist，網站執行時讀取
-   中英雙語用 @nuxtjs/i18n
-   捲動動畫用 Anime.js
-   PDF 由 GitHub Actions 用 headless Chrome 預先產生，文字可以選取
-   SEO 有 sitemap、Schema.org 結構化資料和 Open Graph 圖片

開發與設定說明見 [docs/development.md](docs/development.md)。
